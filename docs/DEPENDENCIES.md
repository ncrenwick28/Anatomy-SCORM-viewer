# Dependencies

Everything the application and the exported player need at run time is bundled from npm at build time; nothing is loaded from a CDN or any other host when the app or a package runs.

Versions below are those installed by `package-lock.json` (run `npm ci`). Licences were read from each package's `package.json`.

### Demonstration content
The four demonstration models (`public/demo/*.glb`) are procedurally generated by `scripts/generate-demo-models.ts` from primitive shapes. They are original work released under **CC0 1.0**, are **schematic and not anatomically accurate**, and carry that statement in their credit field. Their descriptive text is placeholder content for demonstrating the software.
